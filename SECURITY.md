# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The ET Chess team takes the security of our application and users seriously. If you discover a vulnerability or security defect, please report it promptly following responsible disclosure guidelines.

### Reporting Process

1. **Do not** report security vulnerabilities through public GitHub issues or discussions.
2. Email your findings directly to `security@etchess.io` with:
   - A clear description of the vulnerability and affected component(s).
   - Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
   - The potential impact and attack vectors.
3. We will acknowledge receipt within 48 hours and provide regular updates on remediation progress.
4. Once resolved, we will credit responsible reporters in our release notes unless anonymity is preferred.
